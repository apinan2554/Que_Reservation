บทบาทผู้ใช้งาน (User Roles)

4 Roles
📱

ลูกค้า (Customer)

ผู้มาใช้บริการร้านอาหาร

  • สแกน QR หน้าร้านเพื่อรับคิว (ตรวจ GPS)
  • หรือเข้าเมนูจองโดยตรง (ไม่ตรวจ GPS)
  • กรอกชื่อ + จำนวนคน → รับเลขคิว + สลิป
  • ติดตามสถานะคิว Real-time (กระพริบ+เสียงเมื่อถึงคิว)
📋

พนักงาน (Staff)

จัดการคิวในร้าน

  • Kanban Board 3 คอลัมน์: Pending · Calling · Served
  • เรียกคิวถัดไปตามกลุ่มโต๊ะ (A/B/C)
  • เปลี่ยนสถานะ: เข้าโต๊ะ / เรียกซ้ำ / ยกเลิก
  • อัปเดตอัตโนมัติผ่าน SignalR
📺

จอแสดงผล (Display)

หน้าจอหน้าร้านสำหรับลูกค้า

  • แสดงคิวที่กำลังเรียก (Calling)
  • แสดงคิวรอถัดไป (สูงสุด 8 คิว)
  • เล่นเสียงเรียกคิวภาษาไทย (Web Speech API)
  • อัปเดตอัตโนมัติผ่าน SignalR
⚙️

ผู้ดูแล (Settings)

ตั้งค่าระบบ

  • กำหนดเวลานั่งสูงสุดต่อกลุ่มโต๊ะ (นาที)
  • กลุ่ม A: 1-2 คน · B: 3-4 คน · C: 5+ คน
  • สร้าง QR Code สำหรับติดหน้าร้าน
  • ตั้งค่าพิกัดร้าน + รัศมี GPS

สถานะของคิว (Queue State Machine)

4 States
stateDiagram-v2 [*] --> Pending: 📝 ลูกค้ารับคิว Pending --> Calling: 📢 พนักงานเรียกคิว Pending --> Cancelled: ❌ ยกเลิก Calling --> Served: ✅ เข้าโต๊ะ Calling --> Calling: 🔁 เรียกซ้ำ Calling --> Cancelled: ❌ ยกเลิก Served --> [*] Cancelled --> [*]
📝 1. Pending (รอเรียก) — Status = 0
ลูกค้ากรอกชื่อ+จำนวนคน → ระบบจัดกลุ่มโต๊ะ (A:1-2, B:3-4, C:5+) → สร้างเลขคิว (เช่น A001) → SignalR แจ้ง Dashboard
POST /Customer/Register
📢 2. Calling (กำลังเรียก) — Status = 1
พนักงานกดเรียกคิว → หา Pending เก่าสุด → เปลี่ยนเป็น Calling → SignalR ส่งเสียงไปจอหน้าร้าน + อัปเดตหน้า Status
POST /Staff/CallNextQueue?tableGroup=A
✅ 3. Served (เข้าโต๊ะแล้ว) — Status = 2
พนักงานกด "เข้าโต๊ะแล้ว" → คิวถูกย้ายไปคอลัมน์ Served → เสร็จสิ้น
POST /Staff/UpdateStatus?id=1&status=2
❌ 4. Cancelled (ยกเลิก) — Status = 3
ยกเลิกโดยพนักงาน (จาก Pending หรือ Calling) → คิวถูกกรองออกจาก Dashboard
POST /Staff/UpdateStatus?id=1&status=3

ระบบป้องกันการจองคิว — Geolocation Protection

Haversine
flowchart TD A["📍 พิกัดร้าน (StoreSettings)"] --> C["📐 HaversineDistance()"] B["📍 พิกัดลูกค้า (HTML5 Geo)"] --> C C --> D{"ระยะ ≤ 150m?"} D -->|"✅"| E["✅ อนุญาต"] D -->|"❌"| F["⛔ ปฏิเสธ"]
🧮 สูตร Haversine: d = 2R · atan2(√a, √(1−a)) โดย a = sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlon/2)
⚙️ appsettings.json: StoreLatitude, StoreLongitude, AllowedRadiusMeters (150), EnableGeoCheck (true/false)
